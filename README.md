## 繁體中文

### 這是什麼
裝上之後，遊戲裡的對話、戰鬥、人物介紹、道具和技能說明都會同時顯示中文和日文：

- 上面一行是繁體中文（白色，遊戲官方文本）
- 下面一行是日文（一般劇情是黃色，戰鬥畫面是紅色，翻譯來自活俠傳日本語制作会）
- 選單、地名、人名這類只放得下一行的短標籤只顯示中文，狀態欄的直排選單旁邊會另外標上日文小字
- 支援 2026/10/15 的大型更新《崆峒神威》

字體會放大，對話框也會自動加高，讓兩種語言都放得下。

### 安裝方式
1. **下載日文 MOD 最新版**：到 [日文 MOD 官網](https://dlaqe2334.github.io/LOM-JPMOD/) 下載（安裝程式 `.exe` 或 `.zip` 都可以）。
2. **下載雙語包**：到 [Releases 下載頁](https://github.com/enishiyui520/legend-of-mortal-bilingual-mod/releases/latest) 下載 `LOM-Bilingual-Plugin-v1.0.zip`。
3. **確認 Steam 已經把遊戲更新到最新版**，然後關掉遊戲。
4. **蓋上去**：打開遊戲資料夾（`Mortal.exe` 所在的那一層，例如 `C:\Program Files (x86)\Steam\steamapps\common\LegendOfMortal`）。
   - 先裝日文 MOD：執行它的安裝程式，或把它的 zip 全部解壓到這裡。
   - 再把雙語包的 zip 全部解壓到這裡。
   - 不要多包一層資料夾；問要不要覆蓋時，選全部覆蓋。
5. 開遊戲，就會看到中日雙語。

日文 MOD 之後在遊戲裡自動更新時，雙語字幕也會跟著用最新的翻譯，不需要重新下載本外掛。

### 遊戲中的快捷鍵
| 按鍵 | 功能 |
|---|---|
| F7 / F6 | 字放大／縮小（不會小於遊戲原本的大小） |
| F5 | 開關放大功能（含對話框自動加高） |
| F9 | 開關「對話文字一律白色」 |

### 移除
刪掉 `BepInEx\plugins` 裡的 `LOM_Enlarge.dll` 和 `LOM_Bilingual_zh_only_groups.txt` 就會回到只有日文的狀態。要整個移除日文 MOD，請照日文 MOD 官網的說明操作。

### 關於文字內容
本外掛的壓縮檔裡沒有任何遊戲文本或翻譯文字。中文是在你的電腦上從你自己的遊戲讀取，日文是從你安裝的日文 MOD 讀取，兩邊只在遊戲執行時於記憶體中組合。

## 日本語

### これは何？
導入すると、会話・戦闘・人物紹介・アイテムやスキルの説明が、中国語と日本語の二言語で同時に表示されます。

- 上の行：繁体字中国語（白、ゲーム公式テキスト）
- 下の行：日本語（通常のシナリオは黄、戦闘画面は赤。翻訳は活俠傳日本語制作会様によるもの）
- メニュー・地名・人名など一行しか入らない短いラベルは中国語のみ表示し、ステータス画面の縦書きメニューには日本語を小さく添えて表示します
- 2026年10月15日の大型アップデート「崆峒神威」に対応しています

文字は拡大され、二言語が収まるようにダイアログボックスの高さも自動で伸びます。

### インストール方法
1. **日本語化MODの最新版をダウンロード**：[日本語化MOD配布ページ](https://dlaqe2334.github.io/LOM-JPMOD/) からダウンロードします（インストーラー `.exe` でも `.zip` でも構いません）。
2. **二言語パックをダウンロード**：[Releases ダウンロードページ](https://github.com/enishiyui520/legend-of-mortal-bilingual-mod/releases/latest) から `LOM-Bilingual-Plugin-v1.0.zip` をダウンロードします。
3. **Steam でゲームが最新版に更新されていることを確認**し、ゲームを終了します。
4. **上書きで導入**：ゲームのフォルダ（`Mortal.exe` がある場所。例：`C:\Program Files (x86)\Steam\steamapps\common\LegendOfMortal`）を開きます。
   - まず日本語化MODを導入します（インストーラーを実行するか、zip の中身をすべてそこに展開）。
   - 次に二言語パックの zip の中身をすべてそこに展開します。
   - フォルダを入れ子にしないでください。上書きの確認が出たら「すべて上書き」を選んでください。
5. ゲームを起動すれば二言語表示になります。

日本語化MODがゲーム内で自動アップデートされると、二言語字幕も最新の翻訳を使います。本プラグインを入れ直す必要はありません。

### ゲーム内ホットキー
| キー | 機能 |
|---|---|
| F7 / F6 | 文字の拡大／縮小（元のサイズより小さくはなりません） |
| F5 | 拡大機能のオン／オフ（ダイアログの自動拡張を含む） |
| F9 | 「セリフの文字を常に白にする」のオン／オフ |

### アンインストール
`BepInEx\plugins` 内の `LOM_Enlarge.dll` と `LOM_Bilingual_zh_only_groups.txt` を削除すると、日本語のみの表示に戻ります。日本語化MOD自体を外す場合は、配布ページの説明に従ってください。

### テキストについて
本プラグインの zip には、ゲームのテキストや翻訳テキストは一切含まれていません。中国語はお使いのPCのゲーム本体から、日本語は導入済みの日本語化MODから読み込み、ゲーム実行中にメモリ上でのみ組み合わせています。

日本語翻訳とフォント処理は、すべて **活俠傳日本語制作会** 様によるものです。二言語版の制作をご許可いただき、ありがとうございました。日本語化MODは制作会の皆さまが多くの時間をかけて作り上げた作品です。ぜひ [配布ページ](https://dlaqe2334.github.io/LOM-JPMOD/)・[Discord](https://discord.gg/CV26jEGgVU)・[X](https://x.com/Mortal_jp) で応援してください。
